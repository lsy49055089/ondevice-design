# On-Device RTL / FPGA Design

Verilog·VHDL과 FPGA를 기반으로 구현한 디지털 회로 및 SoC 설계 프로젝트를 정리하는 포트폴리오 저장소입니다.

## Focus Areas

- 조합논리·순차논리 및 FSM·Datapath 설계
- Counter, Tick Generator, Clock Divider, UART, FIFO
- Stopwatch 및 주변장치 제어 모듈
- MicroBlaze와 AXI-Lite 기반 GPIO·UART·SPI·I2C 시스템
- RV32I CPU 구조 및 RTL 설계

프로젝트별 소스 코드, 블록 구조, 동작 원리와 검증 결과를 순차적으로 정리합니다.
